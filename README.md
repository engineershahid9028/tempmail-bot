
# TempMail Full SaaS Bot (Merged)
Features:
- Buttons UI
- Temp mail (mail.tm)
- Auto OTP fetch + Inbox
- Premium (free 2/day, premium 5/day)
- Email reuse (premium)
- Referrals (+1/day per referral)
- Crypto payments (manual admin approval)
- Telegram Stars subscription (30 days)
- Web admin dashboard (port 8080)
- Analytics panel

⚠️ For QA/testing on systems you own or have permission to test.

Railway:
- Add PostgreSQL plugin (DATABASE_URL)
- (Optional) Add Redis plugin (REDIS_URL)
- Set BOT_TOKEN, ADMIN_ID
- Generate domain for port 8080 (dashboard)
